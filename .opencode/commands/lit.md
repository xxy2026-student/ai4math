# /lit — 有目的的文献证据

输入：$ARGUMENTS

1. 先确认该检索服务于哪个已批准问题/方向，以及当前 artifact 版本。若是独立主题，先明确临时问题、检索边界和预期输出；不要无目的收藏。
2. 写检索计划：数据库/来源、3–5 条查询线、年份/领域边界、纳入排除条件、预算与停止标准。
3. 派 **scholar** 执行：
   - 主题检索：survey 定坐标，再沿引用图寻找最近邻；
   - 单篇精读：读取可访问原文并写 `literature/papers/<bibkey>.md`；
   - 引用追踪：从已核实笔记扩展前驱/后继并更新地图。
4. 已有笔记只做有来源的增量更新；刷新 `accessed` 并保留重要旧判断的修订记录。地图记录其 `version`、`based_on` 与检索日志。
5. 汇报：新增/更新笔记、支持/削弱了哪些研究判断、最近邻差异、未知和是否达到停止标准。

## 条件门

在既有批准 envelope 内继续检索不重复打断。以下情况暂停并用开放决策卡请求人类决定：需要显著扩大领域/时间/付费访问范围；发现近乎相同工作会改变方向；主要文献证据互相冲突；原检索目标已失效。LLM 必须推荐下一步并给最强反对意见，提供 2–4 个路线选项与自定义项。

## 纪律

- 禁止凭记忆引用；实际核实 `url`、`accessed`、`access-level`。
- `secondhand` 不得支撑具体论断；区分论文结果、作者声称和我们的推断。
- 新颖性只能写“在所列检索范围内未见”，不能写“文献中不存在”。
- 文献更新若推翻上游假设，标记相关 grounding/model/design/claim 为 `stale`，不要静默沿用。
